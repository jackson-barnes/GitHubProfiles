# GitHub Profiles

A small native iOS application for exploring GitHub users profiles and their public repositories.

Users can search for GitHub accounts, view profile information and public repositories, and open individual repositories directly on GitHub.

## Features

* Search GitHub users as you type
* Debounced search requests
* Display user avatar, username and account type
* View GitHub profile information
* View public repositories
* Display repository descriptions, languages, stars and forks
* Open repositories in an in-app web view

## Requirements

* **Xcode 26**
* **Swift 6.2**
* **iOS 18.0+**

## Getting Started

1. Clone or download the repository.
2. Open `GitHubProfile.xcodeproj` in Xcode.
3. Select an iOS Simulator or connected iOS device.
4. Ensure the deployment target is set to **iOS 18.0 or later**.
5. Build and run the application.

No API keys, environment variables or additional dependencies are required.
